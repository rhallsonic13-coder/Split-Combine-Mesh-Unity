# Split-Combine-Mesh-Unity
Two super-handy tools! Combining and Separating Meshes. Simple Editor Plugins.

### ⚡How To Use:
- Download the Editor folder and import it into your project. Open it by going to Tools > Mesh Separator and Tools > Mesh Combine.
